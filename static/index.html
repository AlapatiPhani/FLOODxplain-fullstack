⚙️ System Workflow
📷 1. Input Image
Satellite or drone flood imagery is uploaded for automated analysis.
🧠 2. DL Prediction
ResNet-50 classifies the scene as flood or non-flood with confidence scores.
🔥 3. XAI Heatmaps
GradCAM and GradCAM++ highlight the image regions used by the model.
📊 4. Impact Metrics
Flood output is linked with maps, roads, buildings, risk, and recovery indicators.
📋 5. Report Support
The system exports field reports and supports infrastructure, recovery, and reporting workflows.
